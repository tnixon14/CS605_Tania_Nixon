This is a simple calculator that solves a problem with two numbers and an operation. 
Valid operations are subtraction, addition, division, and multiplication.

To use the calculator, simply run the file and pick one of the valid operations:

+: for addition\
-: for subtraction\
*: for multiplication\
/: for division

Next, enter your first number and the second number, and it will output the answer.
Finally, it will ask if you would like to do another calculation. Type either YES or NO; it is not case-sensitive.
